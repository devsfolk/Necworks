# Media inbox

Put original photos in `machines/<slug>/`, `knowledge/<slug>/`, or `projects/<slug>/`. Name photos `01.jpg`, `02.jpg`, and so on. Video files can be `.mp4` or `.mov`; name a poster image `<video-name>-poster.jpg`.

Keep your own backup of originals, they are not in Git.

AI enhancement is allowed only for noise, sharpness, colour, background cleanup, stabilization; never add, remove or change machine parts.
